# Validation Audit & Improvement Options

This note documents (1) the six-pass upstream & adversarial validation audit performed across OpenSpec, GitHub Spec Kit, Google ADK `v2.15.0`, Python `3.14` / `uv` / Copilot+Gemini / Windows+macOS engineering, Claude Projects, and modern SDD/security/UI standards, including concrete bugs caught in earlier drafts, and (2) **24 high-leverage architectural, security, verification, coding, stability, context-scaling, and UX improvements**.

## 2. Twenty-Four Concrete Improvement Options Beyond OpenSpec & Spec Kit

### Core Architecture, Governance & Merge Safety (Improvements 1–5)

1. **Fingerprint-Guarded 3-Way Delta Merge Engine:** Capture SHA-256 base requirement hashes and raw baseline blocks in `.change.yaml`. Verify before archive; perform deterministic 3-way `diff3` merge on divergence; fall back to a focused `ConflictResolverAgent` + `ToolConfirmation` only when genuine line/scenario collisions exist—eliminating OpenSpec's silent scenario drop bug.
2. **Runtime-Enforced Write Contracts (`WritePolicyPlugin` + `tool_filter`):** Enforce read-only (`explore`, `analyze`), append-only (`verify_converge`), and reviewer-owned `checklists/` locks via least-privilege `tool_filter` + path-normalized `WritePolicyPlugin`, rather than trusting Markdown prompts.
3. **Executor + Budgeted Reasoning Advisor (`ModelConsultTool` + `ForceEscalationPlugin`):** Run drafting/mechanical stages on fast Flash models with hard `max_uses`/`session_max_uses` escalation budgets to a tool-less Pro advisor, instrumented by `ModelConsultObservabilityPlugin`.
4. **Shared Prefix Caching & Non-Destructive Compaction:** Enable `ContextCacheConfig` (for constitution/specs prefixes on turn 2+) and `EventsCompactionConfig` on `App` so long SDD threads never overflow context while keeping raw events in storage.
5. **Pluggable Sandboxed Environments (`EnvironmentToolset`):** Build on `LocalEnvironment` locally and swap a single constructor argument to `E2BEnvironment`/`DaytonaEnvironment` for untrusted code execution and isolated `SkillToolset` scripts.

### Workflow Extensibility, Traceability & Lifecycle (Improvements 6–10)

6. **Declarative YAML Workflow Overlays Compiled onto ADK Graphs:** Compile Spec Kit-style `insert_after`, `insert_before`, `replace`, and `remove` overlays (lower-wins priority) onto ADK `Workflow` edge lists before graph construction so ADK validates every customized org pipeline at startup.
7. **First-Class `contracts/` Layer + Spec-of-Specs `roadmap.md`:** Model external API/event contracts (with idempotency, retry, timeout, and owner metadata) and shallow `roadmap.md` (`R1..Rn` immutable IDs) inside the DAG for oversized epics.
8. **Eval-Driven Prompt Optimization & Migration Gate (`AgentEvaluator` + `GEPARootAgentPromptOptimizer`):** Lock Phase 1 golden suites (`*.test.json`), tune `static_instruction` systematically, and gate every Phase 2–4 LLM→Python migration on passing `AgentEvaluator` parity with lower token/latency metrics.
9. **Hardened Workspace & MCP Boundary Security:** Enforce `relativePathSchema` traversal checks, symlink/junction denial, `1 MiB` MCP payload caps, bounded pagination (`<= 1000`), `ToolCallIntegrityPlugin` HMAC stamps on agent tool checkpoints, and `ToolConfirmation` on destructive ops.
10. **Continuous Spec-to-Code Drift Detection:** Read-only `drift-check` workflow (run on CI or `ServiceTier.DEFERRED` schedules) comparing recent Git commits against `.spec/specs/` and drafting remediation proposals when code drifts out-of-band.

### Modern SDD, Coding Structure, Stability & UI/UX Upgrades (Improvements 11–16)

11. **EARS + RFC 2119 + 4-Hash BDD Hybrid Grammar:** Combine AWS Kiro's 5 deterministic **EARS** sentence patterns (*Ubiquitous, Event-driven, State-driven, Optional, Unwanted behavior*) with OpenSpec's `#### Scenario:` (`GIVEN`/`WHEN`/`THEN`) and `<= 500` char requirement cap for near-zero ambiguity and direct test compilation.
12. **Executable Specifications & Bidirectional Traceability Matrix:** Link `Roadmap R#` → `REQ-ID` → `#### Scenario:` → `contracts/` schema → `Task T### [US#]` → `@pytest.mark.spec("cap:REQ-ID")` markers, letting deterministic Python compute real Spec Coverage % in CI and `analyze`.
13. **Git Worktree Isolation for Parallel Active Changes:** Automatically provision dedicated Git worktrees (`git worktree add`) per parallel `[US#]` change or independent `roadmap.md` slice during `apply`, eliminating cross-branch working-tree contamination across concurrent coding agents.
14. **Hexagonal Architecture + Safe Strangler-Fig Stage Registry (`llm | shadow | hybrid | python`):** Keep `domain/` completely pure (zero ADK/LLM imports) behind typed `Protocol` ports; support `allow_shadow`-guarded `shadow` fan-out runs on pure/read-only stages (`(LlmNode, PythonNode) → JoinNode` with cloned names and forwarded schemas) to verify Python parity before cutover.
15. **Production Stability, Privacy & Cost Stack:** Combine `FallbackModel` (429/503 failover), `ReflectAndRetryToolPlugin` + `ReflectAndRetryModelPlugin`, `RunConfig(max_llm_calls, StreamingMode.SSE, ToolThreadPoolConfig, TelemetryConfig(NO_CONTENT))`, `BufferedSessionService` (with explicit `flush_session()`), and `ServiceTier.DEFERRED` for background batch workflows.
16. **Cross-Session Architectural Memory (`BaseMemoryService`) & Out-of-Band `ArtifactService` + AG-UI/A2UI Workbench:** Use `ArtifactService` for heavy diffs/reports, `BaseMemoryService` to recall historical design rejections/ADRs across sessions, and replace the "chat wall" with an **ADK + FastAPI + AG-UI 1.0 + A2UI** Spec Review Workbench paired with a sanitized Rich TUI (`adk-spec view`).

### Frontier Security, Anti-Tautological Verification, Rewind & Spatial UI Upgrades (Improvements 17–21)

17. **Defense-in-Depth OWASP Agentic Security Stack (`ASI01`/`ASI02`/`ASI05`/`ASI06`):** Pair `BaseToolset(tool_filter=...)` least-privilege with path-normalized `WritePolicyPlugin` blocking `Execute` on RO/converge nodes, narrow domain tools (`append_convergence_tasks`), `ModelArmorPlugin` `after_tool_callback` screening against indirect prompt injection, and human-approved-only memory ingestion into `BaseMemoryService`.
18. **Anti-Tautological Verification Pipeline (`Hypothesis` PBT + `mutmut` Mutation Testing + `import-linter`):** Derive `Hypothesis` property tests from EARS invariants, run `mutmut` in `strict` `verify_converge` to expose weak AI-generated tests, and enforce Hexagonal + `constitution.md` architectural layers via `import-linter`.
19. **`static_instruction` Caching + `BuiltInPlanner` Thinking Budgets + Built-In ADK Efficiency Evals & `ToolArgsMatcher`:** Split immutable instructions into `static_instruction` for Gemini caching & GEPA optimization, assign stage-specific `ThinkingConfig` budgets, and adopt ADK's zero-config `token_usage_v1` / `inference_call_count_v1` / `invocation_duration_v1` + `ToolArgsMatcher` for non-brittle eval gates.
20. **Native Time-Travel Session Rewind (`Runner.rewind_async`) & A2A Cross-Team Spec Federation (`to_a2a` / `RemoteA2aAgent`):** Let reviewers scrub back to any earlier invocation cleanly via `rewind_async`, and let platform teams serve living specs over HTTP JSON-RPC via `to_a2a` without forcing monorepo merges.
21. **Spatial React Flow DAG Canvas, Plannotator AST-Anchored Inline Review Annotations, SSE `Last-Event-ID` Reconnect & Mobile Approval Inbox PWA:** Elevate the Workbench with a live `@xyflow/react` node graph, Plannotator-style inline markdown annotations delivered as AST/line-range patches, resilient `Last-Event-ID` SSE cursor recovery, and a swipe/keyboard-driven mobile approval inbox.

### Scoped Knowledge Workspaces, Auto-Scaling RAG & Artifact Flywheel (Improvements 22–24)

22. **Two-Tier Auto-Scaling Context Loader (`Direct Cache` → Automatic `spec_knowledge_search` RAG) & Live Capacity Meter:** Model Claude Projects' seamless full-context-to-RAG transition cleanly across variable Copilot and Gemini context windows. Under the active model's token/file budget, inject `.spec/knowledge/` (non-spec ADRs, glossaries, runbooks) directly into `LlmAgent.static_instruction` for maximum Gemini `ContextCacheConfig` hits; once exceeded, automatically switch to a compact ToC + deterministic pure-Python BM25/heading `spec_knowledge_search` tool (scaling ~10x capacity with zero vector DB initially; optionally hybrid semantic via `BaseMemoryService` in Phase 4) alongside a visible Workbench capacity & mode badge.
23. **Selective Path Allowlisting + Manual Pinned Sync + `isolated_memory` Wall:** Add a `knowledge:` include/exclude manifest in `.spec/config.yaml` (`1 MiB` per-file cap; skipping binaries/lockfiles) pinned to LF-normalized SHA-256 + git rev snapshots in `.spec/.knowledge-lock.json`, refreshed strictly via explicit `adk-spec knowledge sync` or UI `[↻ Sync Knowledge]` (matching Claude Projects' manual GitHub Sync stability guarantee). Partition `BaseMemoryService` by `(app_name, project_id)` with an explicit `isolated_memory` toggle (default `true` in `strict`) so client/regulated repos never cross-pollinate, while parallel `explore`/`assess`/`change` threads stay transcript-isolated.
24. **Human-Gated Artifact-to-Knowledge Flywheel (`Promote to Knowledge`) & Team `Can view`/`Can edit` RBAC:** Let users promote vetted exploratory memos/diagrams from `explore` and `assess` artifacts straight into `.spec/knowledge/<slug>.md` or `.spec/changes/<id>/proposal.md` with one click + diff confirmation (avoiding chat-log pollution while preserving `ASI06` quarantine), prefer affirmative structural context over negative prompt lists (`WritePolicyPlugin` enforces bans), and support Phase 4 scoped Store/Workbench roles (`Can view` vs. `Can edit`, resetting sharing on archive).
